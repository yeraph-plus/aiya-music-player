# docs/26 — 背景频谱山形化 + 正在播放页可视化调研

日期：2026-10-26。背景：docs/25 T4h 用户四点反馈——背景频谱不再用柱状（改山形），正在播放页单独加一个居中式频谱可视化。

---

## §1 先回答：小 canvas 画完再放大，是性能考虑吗？

**是，且是两个原因叠加：**

1. **模糊的代价 ∝ 像素数**。`ctx.filter = blur(26px)` 的开销随画布面积线性增长（每像素要采样半径内邻居）。全窗 2560×1440@2x 下做 26px 模糊每帧都是大钱；在 160×90 的 buffer 上做同样模糊便宜约 **250 倍**，放大回全窗由 GPU 合成器做，几乎免费。
2. **放大自带免费柔化**。`drawImage` 低分辨率 → 高分辨率的默认双线性插值本身就是一层模糊，等于"画 3px 的柱，得到 30px 的柔光"。T4g 曾把这层插值当 bug 修掉（沉浸档直出），现在山形方案里它正是虚化的一部分。

所以背景层继续保留低分辨率 buffer 管线，只换画法。

## §2 背景层：山形曲线（已实现，T4h）

柱状为什么不适合背景：柱子有明确的"底部基线"，视觉语义是"仪表/测量"；且硬边柱阵经模糊后是均匀的雾，没有形体。山形（filled ridge）的视觉语义是"地形/氛围"，模糊后仍有可辨识的形体起伏。

**画法（`AmbientBackdrop.svelte`）：**

- 48 带先做**时间平滑**（每帧向目标值靠拢 30%，起音跟手、衰减绵长，山不随帧抖）+ 轻微伽马（v^1.2）压低持续偏热的低频带。
- **中点二次贝塞尔**连成山脊线：控制点取数据点、锚点取相邻中点，C1 连续无折角。
- 闭合到底边填充垂直渐变（山峰浓 → 底边透明），山是"光"不是实心块。
- **两层纵深**：远山（倒序带 + 0.5 倍振幅 + alpha 0.35）垫底，近山（主形 + alpha 0.7）在上。
- standard 档 blur(26px) / alpha 0.5；沉浸档（正在播放页）**加回虚化**（用户 T4h 要求）blur(14px) / alpha 0.75——虚化但保留山形可辨识度。
- 遮罩逻辑不变：仅 standard 档渲染。背景层回到**整个窗口**（用户拍板不再让位）。

## §3 正在播放页：居中式可视化候选方案

数据同源（48 带实时频谱 tap，`SpectrumSource`），差别只在渲染层。检索参考：music-waveform 的八形态分类（bars/mirror/radial/scope/area/dots/blob/circle）、Siri-style 贝塞尔对称曲线（CodePen gist）、audioMotion-analyzer（径向/LED/lumi 形态）、AeroPlayer 14 形态清单。

| 方案 | 观感 | 实现要点 | 成本/风险 |
|---|---|---|---|
| **A 镜像对称曲线**（Siri 式） | 水平中线上下对称的两条平滑贝塞尔呼吸，描边发光 + 半透明填充，优雅、居中、与两栏沉浸页气质最合 | 48 带插值 → 中点贝塞尔一条曲线，中线镜像第二条；shadowBlur 发光。纯 2D，一帧两条 path | 低。纯 Canvas 2D，无新依赖 |
| **B 径向环形** | 频谱绕圆一周向外呼吸，冲击力最强，可把封面放圆心 | 每带旋转画短弧/柱；平滑同理。圆形排布下低频在正下方需旋转起始角 | 中。视觉调参多；与"折曲线"诉求偏离 |
| **C 示波线（Scope）** | 单条连续曲线沿频带起伏，技术感、催眠 | 一条 path，最轻 | 低。但视觉存在感弱，"炫酷"不足 |
| **D 3D 地形 / 粒子流** | 最炫酷（滚动地形、粒子爆发） | WebGL 或逐像素写入；需要新依赖或大量手写 | 高。风险大，与本批"轻迭代"节奏不符，不建议首发 |

**推荐 A**：曲线式、居中、性能安全、实现小；若想要更"炫"再叠 B 作为第二形态（设置里的「频谱风格」正好可以接上真实语义）。

## §4 落地记录

- T4h：§1/§2 已实现（背景山形 + 沉浸档虚化回归 + 频谱设置两项迁入外观组并如实标注「频谱风格」当前无生效入口）。
- §3 **方案 A 已实现**（用户拍板）：`NowPlayingSpectrum.svelte`——居中镜像对称曲线，垫在两栏内容后（z-index 0 / 内容 1）。要点：
  - **共享源引用计数**：背景层与页面层共用同一 `RemoteSpectrumSource` 实例，`start()/stop()` 改为引用计数叠放——tap（`spectrum_set`）是全局开关，不计数的话页面卸载会把背景层的 tap 一起带走（原实现单消费方假设，T4h 升级）。
  - 镜像带序列（左半倒序 + 右半正序）→ 中点二次贝塞尔 → 上下对称曲线 + shadowBlur(16) 发光描边 + 透镜区渐变填充（alpha 0.16）。
  - 时间平滑 0.25/帧；amp = 页高 16%；reduced-motion 不渲染；数据源为 null（设置关/引擎失败）不渲染。
  - 「频谱风格」设置项（pro/compact）仍是待接线的存储偏好：正在播放页新可视化为单一形态，后续若加多形态可让它接管语义。
- **频谱风格接线（用户需求「让频谱风格控制正在播放页的曲线，做几个模式」）**：新增设置键
  `spectrumStyle: 'mirror' | 'radial' | 'wave'` 取代已死的 `spectrumEngine`（compact/pro）——
  沿用 `accentFromArtwork → ambient` 的淘汰惯例：旧键停写停读（存量 blob 里的旧值经
  `mergeSettings` 默认值兜底，passthrough 不报错），Rust `DEFAULT_SETTINGS` 同步换键
  （顺手清掉 ambient 迁移时漏掉的 `accentFromArtwork`）。三形态共用一帧循环，形态切换
  只换画笔不重启订阅（tap 引用计数，不因切风格开关引擎）：
  - `mirror` 镜像曲线：即方案 A 原样（默认）；
  - `radial` 径向环形：48 带绕圆一周（首尾相接天然对称，无需镜像），r0=短边 20%、
    amp=13%，慢速旋转 0.05 rad/s，径向渐变环带填充 + 内圈基线 + 峰值环发光描边；
  - `wave` 示波线：单条曲线沿频带起伏（低→高左→右），amp=页高 20%，曲线下"声面"
    渐变填充 + 极淡中线基线 + 发光主曲线。
  - 设置页「频谱风格」hint 更新为真实语义；背景环境光固定山形、不受此项影响。
  - 修复记录：本批顺带修掉 T4h 回归——背景山形带值被二次归一化（`frame()` 已归一化
    0–1 又除 255），峰值只剩 ~0.4%，山脊贴底成 1px 平线（0f00755）。
